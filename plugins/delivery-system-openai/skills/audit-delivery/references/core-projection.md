# Core Projection：Audit Delivery

> 来源：Delivery System Core `0.1.0-draft`
>
> 状态：受控同步投影，不得作为独立规则源修改。

- Audit Delivery 是独立、只读角色；不得直接修复或接受自己的建议。
- 审查应覆盖需求、架构、Issue、变更和 Closure 的适用维度。
- Finding 必须包含 ID、严重度、类别、证据、影响、建议、受影响产物和所需决定。
- 审查者必须区分事实缺陷、风险、建议、偏好和用户决定；缺乏证据时必须说明限制。
- 用户决定 Finding 后，Idea to Delivery 修订规划产物，Execute Delivery 根据批准的修复 Issue 改动实现。
