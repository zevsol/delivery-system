# Core Projection：Idea to Delivery

> 来源：Delivery System Core `0.1.0-draft`
>
> 状态：受控同步投影，不得作为独立规则源修改。

- Core 是角色、产物、追踪、质量门和变更语义的唯一事实来源。
- Idea to Delivery 负责 Discovery、Requirement、ADR、Roadmap、Issue 分解、基线维护和 Change Management。
- 关键未知必须形成 Clarification Request、Research Task、Spike、ADR Decision Required 或 Blocked Issue。
- 每个 Issue 必须追溯到 Requirement、ADR、风险、缺陷或维护目标；每项关键验收标准必须有验证方法。
- 新需求只有在不改变目标、不产生新能力、不扩大测试、不改变架构或依赖且仍按原验收标准闭环时，才可作为 Clarification 留在原 Issue。
- 未获用户批准的产品、架构、审查或发布决定不得写为既成事实。
