# V0 完善任务总览

> 基线：V0 本地安装候选版
>
> 测试策略：所有真实 Skill 场景、宿主触发和最终验收均保留到项目所有者启动测试阶段后执行。

本目录把原始规划中的 V0 缺口、公开前检查和后续维护任务集中管理。`docs/release/openai-codex-release-checklist.md` 是发布操作清单；本目录负责说明先完成什么、为什么完成、由谁完成以及何时允许进入测试。

| ID | 任务 | 状态 | 依赖 |
|---|---|---|---|
| TASK-001 | 补齐 Core 治理产物 | completed | 无 |
| TASK-002 | 补齐用户与维护者文档 | completed | TASK-001 |
| TASK-003 | 建立版本、发布与跨平台路线 | completed | TASK-001, TASK-002 |
| TASK-004 | 建立测试执行包并等待测试授权 | pending | TASK-001–003 |
| TASK-005 | V0 独立交付审查与发布决定 | pending | TASK-004 |

## 执行规则

- `core/` 仍是唯一交付语义来源；Adapter 和分发包只能同步其语义。
- 已完成不代表产品验收通过；它表示非测试实现和文档已完成并可交给测试。
- TASK-004 前不得运行真实 Skill 场景、宿主触发或最终验收测试。
- TASK-005 只给出独立审查结论与发布建议；最终发布决定始终属于项目所有者。
