## 执行规则

- `core/` 仍是唯一交付语义来源；Adapter 和分发包只能同步其语义。
- 已完成不代表产品验收通过；它表示非测试实现和文档已完成并可交给测试。
- 在 TASK-004 启动前，不将真实 Skill 场景、宿主触发或最终验收的结论视为已验证；不依赖测试结果的架构和文档工作可以独立推进。
- TASK-005 输出独立审查结论与发布建议；发布由仓库维护者依照发布策略决定。
